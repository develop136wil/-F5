# 복지F5

복지정보 담당자의 원문 확인·정리·정책 변경 검토를 돕는 Windows 앱입니다.
수집·분석 결과는 검토 자료이며, Notion 반영은 담당자가 확인하고 선택합니다.

## 개발

- [소스 구성과 빌드·시험 방법](source/README.md)
- [AI 활용 방식](docs/AI_IMPROVEMENT_EVIDENCE.md)
- [운영 안내와 외부 구성요소](docs/OPERATIONS_AND_EVIDENCE.md)

이 저장소는 검토를 마친 제품 소스를 관리합니다. 개발 중 후보나 로컬 내부 검토 기록,
업무 데이터·개인 설정·인증정보·빌드 산출물은 포함하지 않습니다.
소스 공개와 Windows 설치 파일 배포는 별도 단계입니다. 현재 이 저장소의 릴리스에는 설치 파일을 게시하지 않았습니다.
